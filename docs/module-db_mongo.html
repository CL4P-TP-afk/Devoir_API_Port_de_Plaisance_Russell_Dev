Module: db/mongo

Connexion MongoDB (Mongoose). Variables d'environnement utilisées : - MONGO_URI (prioritaire) ou URL_MONGO (fallback) - MONGO_DBNAME (optionnel si non présent dans l'URI) Exporte : - initClientDbConnection : initialise la connexion, installe les listeners (open, close, reconnect, error), et gère la fermeture propre en SIGINT.
