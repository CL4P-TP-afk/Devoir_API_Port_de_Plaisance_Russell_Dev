Module: middlewares/private

Middleware d'authentification (JWT requis). Sources possibles du token : - Cookie `token` - En-tête HTTP `Authorization: Bearer ` Comportement : - ✅ Succès : injecte `req.user` et `res.locals.user` (pour les vues EJS), puis `next()`. - ❌ Absence de token : 401 avec `'token_required'`. - ❌ Token invalide/expiré : 401 avec `'token_not_valid'`.

Methods

(inner) privateMiddleware(req, res, next) → {void}

Middleware Express qui : 1) récupère le JWT depuis `req.cookies.token` ou `Authorization: Bearer ` 2) vérifie la signature avec `SECRET_KEY` 3) expose `req.user` et `res.locals.user` pour la suite de la requête

Example
const privateMiddleware = require('./middlewares/private');
router.get('/dashboard', privateMiddleware, (req, res) => {
  // `req.user` est disponible ici
  res.render('dashboard', { user: res.locals.user });
});
